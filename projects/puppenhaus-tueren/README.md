## Türen ohne Griff (`doors.py`)

Drei Türblätter nach Foto 02 (Wohnungstür) und Foto 03 (Zimmertür mit Lüftungsgitter, Zimmertür mit Glasausschnitt), 1:12, einseitig: Rückseite flach auf dem Bett (z = 0), alle Details oben. x = 0 ist die Schlosskante (in allen Fotos links), der Drücker zeigt nach +x zur Bandseite.

```bash
python3 projects/puppenhaus-tueren/doors.py                 # out/<tür>_ohne_griff.3mf + _report.json
python3 projects/puppenhaus-tueren/doors.py --glass matt --glass-variants offen --png /pfad/doors.png
```

Griff-Hook für die Integration: `doors.handle_mount(spec)` liefert die Drückerachse auf der Türfläche (x, y, z in Druck-mm), `lever_dir = +1` (+x) und eine Langschild-Freihaltezone; `build_door(spec) -> (Manifold, info)` legt dort kein Feature an (`info["handle"]["keepout_free"]`).
