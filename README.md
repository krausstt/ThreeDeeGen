# ThreeDeeGen

Parametrische und generative 3D-Druck-Modelle als Code. Jede Druckdatei wird aus einem Python-Generator erzeugt und automatisch auf Druckbarkeit geprüft (wasserdicht, Körperzahl, Überhänge, bei Mechaniken zusätzlich Kollisions-/Funktionstest).

## Projekte

| Projekt | Beschreibung | Material | Status |
|---|---|---|---|
| [mae-west-eiffel](projects/mae-west-eiffel/) | Generative Fusion aus Mae West (München) und Eiffelturm, 180 mm | PLA | fertig, ungedruckt |
| [bike-bell-bayonet](projects/bike-bell-bayonet/) | Bajonett-Aufnahme + Lenkerband für Decathlon-Fahrradklingel | TPU bzw. PETG + TPU | Entwurf, axiale Maße offen |

## Schnellstart

```bash
pip install -r requirements.txt
python3 projects/<slug>/generate.py --help      # alle Parameter als Flags
python3 projects/<slug>/generate.py             # schreibt nach projects/<slug>/out/
ruff check . && python3 -m pytest -q            # Lint + Smoke-Tests
python3 scripts/new_project.py <slug> "<Titel>" # neues Projekt anlegen
```
